# 自由拖拽

桌面和 iOS 用同一套规则：一棵树里的任何一项都可以拖到任何位置。子项可以拖到外面，外面的项可以拖进某个子项、子子项下面，子子项也可以拖回子项或顶层。

- 落点算法：`src/dragTree.ts`（纯函数，带测试 `src/dragTree.test.ts`）。
- 执行：`model.placeTodo`，store 里是 `place(id, target)`。
- 界面只负责三件事：把看得见的行摊平、把指针位置换算成「空隙 + 想要的深度」、画反馈。

## 1. 模型：空隙 + 深度

拖动开始时，把当前看得见的行按显示顺序摊平成 `DragRow[]`，每行带深度（顶层是 0）、父项、列表、是否完成、是否折叠着子项。

1. **被拖的那一项连同子孙一起拿掉**（`restRows`），剩下的行之间有 `rest.length + 1` 个空隙。所以不可能拖进自己的子孙里。
2. **纵坐标决定空隙**：指针在哪两行的中线之间，就是哪个空隙。
3. **横坐标决定深度**：想要的深度 = 开始拖时的深度 + 横向位移 ÷ 每级缩进（`depthFromOffset`），四舍五入。往右拖一级缩进的距离就深一级，往左就浅一级。
4. **夹到空隙允许的范围里**（`depthRange`）：
   - 最深 = 上一行的深度 + 1，也就是成为上一行的子项。第一个空隙只能是 0。总深度不超过 `MAX_DEPTH`（8 级）。
   - 最浅 = 下一行的深度。否则下一行会被迫「换父亲」。最后一个空隙最浅是 0。
5. **算出落点**（`projectDrop`）：
   - 新父项：往上找第一行深度 = 深度 − 1 的；深度 0 时是顶层。
   - 在兄弟里的位置：数空隙前面有几个同父、同完成状态的兄弟。
   - 落到折叠着的父项正下方、深一级时，排到它子项的最后。
   - 落回原处时标 `unchanged`，不改数据。

例子（`A > A1 > A1a`、`A > A2`、`B > B1`、`C`）：

| 操作 | 空隙 / 深度 | 结果 |
| --- | --- | --- |
| A1a 往左一级 | A1 和 A2 之间 / 1 | A 的子项，排在 A1 后面 |
| A1a 拖到最下面再往左到底 | 最后 / 0 | 顶层，排在 C 后面 |
| C 拖到 B1 下面再往右 | B1 下面 / 2 | B1 的子项 |
| C 拖到 A1a 下面 | A1a 下面 / 2 或 3 | 2：A1 的子项（A1a 的弟弟）；3：A1a 的子项 |
| B 拖到 A 和 A1 之间 | 想要 0，被夹成 1 | A 的第一个子项，B1 跟着走 |

## 2. 放下以后（`placeTodo`）

- 子孙跟着走，列表跟随新父项。
- 放进折叠着的父项时自动展开，免得刚放进去的项「消失」。
- 只改被拖那一项的 `order`：取两个新邻居的中点。多端同步时，两台设备拖不同的项互不影响。
- **完成状态**：已完成的排在未完成后面。未完成的项拖到已完成的兄弟之间，会排在未完成的最后；已完成的项只在已完成里排。
- **VERIFY**：顶层项本身就是待测。
  - VERIFY 里的顶层项拖成子项时，打上待测标记，「待验证」不丢。
  - 子项拖成 VERIFY 顶层时，去掉待测标记。
- **FOCUS**：拖到最上面（第一个空隙、深度 0），就成了新的 NOW。NOW 卡上的子任务也是树的一部分：可以拖出来成队列里的一项，队列里的项也可以拖进 NOW 的子任务。
- 同步时这次移动只改一两个寄存器（位置、顺序），和别的设备上的改动照常自动合并。

## 3. 反馈（两端一致）

- **浮起**：被拖的那一项连同子孙浮起来，跟着指针走，带子项数角标。原位置留一条等高的空位。
- **插入线**：画在空隙上，左端缩进到落点深度。左端有一个小圆点，深度变化时线左右滑动（120ms）。
- **新父项高亮**：落点有父项时，给父项那一行一个淡淡的底色；拖到它的子项区时，父项左侧出现一条竖线连到插入线，说明「会挂在它下面」。
- **悬停展开**：在折叠着子项的行上停 600ms，自动展开，可以继续往里拖。
- **自动滚动**：拖到滚动区上下边缘时自动滚，越靠边越快。
- **取消**：桌面按 Esc，或拖回原处；iOS 拖回原处，或拖出列表区松手。取消时浮起的项飞回原位（减少动态效果时直接回去）。
- **撤销**：结构变了（换了父项或层级）时，弹提示条「已移到「父项标题」下 · 撤销」，5 秒内可以撤销（用 `place` 放回原来的父项和位置）。只是同级换位置时不弹。

## 4. 桌面

- **开始拖**：在行上按住鼠标移动超过 5px。按钮、输入框、编辑中的文字不触发。悬停时出现的拖拽点只是提示，整行都能拖。
- **深度**：每级缩进 = 子项实际缩进的像素（目前约 24px），按鼠标的横向位移算。按住 ⌥ 时锁定深度不变，只做上下排序。
- **列表目标**：
  - 拖到侧栏的列表项或页签胶囊上，就是换列表，整棵移过去成顶层：FOCUS 排在 NOW 之后（`sendToFocus`），VERIFY 等于送去验证，其它列表排最前。
  - 停 800ms 不放，就切到那个列表，可以继续拖进它的树里。
- **NOW 卡**：卡片本身和它的子任务都参与摊平。拖到卡片标题区，等于第一个空隙、深度 0，也就是设为现在，沿用现有的交接动画。

## 5. iOS

- **开始拖**：长按浮起，原地松手就照旧弹出上下文菜单；浮起后手指移动超过 8pt，收起菜单进入拖动。左右滑手势不受影响，因为没有长按就不会进入拖动。
- **深度**：每级 = 子项缩进（约 24pt），按手指的横向位移算。
  - 深度每变一级，给一次 selection 触感，插入线左右滑动。
  - 深度切换带一点迟滞：要多越过约 1/4 级才切换，避免手指轻微抖动时在两级之间来回跳。
- **列表目标**：原生页签栏收不到网页里的拖动，iOS 上不支持拖到页签换列表，用长按菜单里的「移到…」。
- **Duo 双页**：左右两页各自是一棵树的一部分。FOCUS 页从右页的队列拖到左页的 NOW 卡或它的子任务里，可以设为现在，或挂到 NOW 下面。拖过折痕时插入线不画在折痕区。
- **触感**：浮起 .medium，经过新空隙或深度变化 .selection，放下 .light，取消不给。

## 6. 边界情况

| 情况 | 处理 |
| --- | --- |
| 拖进自己的子孙 | 子孙在拖动时被拿掉，不会出现这种落点 |
| 拖到父项和它第一个子项之间 | 只能成为这个父项的第一个子项（深度被夹住） |
| 超过 8 级 | 夹在 8 级 |
| 已完成的项 | 能拖，只在已完成里排位置；未完成的项排不到已完成的后面 |
| HISTORY、回收站 | 不能拖 |
| 编辑中的行 | 不能拖，先结束编辑 |
| 拖动中远端同步改了数据 | 放下时按最新数据重新算一次落点；被拖的项已被别处删掉就取消 |
| 拼音输入法、减少动态效果 | 不受输入法影响；减少动态效果时没有飞行和滑动动画，只有插入线 |
