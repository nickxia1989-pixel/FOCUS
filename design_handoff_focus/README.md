# Handoff: FOCUS — 全平台重设计（F「一件事」）

## Overview
FOCUS 是旅行者自用的 TODO 应用：FOCUS（当下要做）/ VERIFY（做完待测）/ INBOX（随手记）/ GOAL（长期目标）四个列表，加上 HISTORY（完成记录）和回收站；多个 profile（iOS 上叫「空间」）；桌面（Electron，Mac / Windows）与 iOS（Capacitor，含 iPhone Duo）通过坚果云 WebDAV 同步。

这次重设计的目标是**做出品牌感，不再像工具**。定稿方向是第二轮的 F「一件事」：

- **FOCUS 的意思就是一次只做一件。** FOCUS 列表最上面那件事被放大成一张荧光绿的 **NOW 卡**，子任务、完成、送去验证都在卡上；其余的排在「接下来」，序号 02、03…，越往后越淡。
- **完成的那一下是「换场」**：NOW 卡被抽走，下一件升上来接替并变绿。普通行完成时迸出 6 颗星芒。
- **荧光绿 #D6FF3D 只给「现在这一件」**，别处一律不用；荧光绿上永远是近黑色的字。
- 图标：FOCUS = **星芒**（旅行者指定），VERIFY = **眼睛里一个勾**（再看一眼）。不再用「圈里一个点」和烧瓶。

设计稿（Claude Design 画布，私有）：https://claude.ai/artifact/CxbBWQsfjGLduf7SFZb7Ui ——「F · 定稿」页是本交接包的内容；「组件」页是可调参数的组件；「第一轮」「第二轮」是被否掉 / 没选的探索，仅供参考。

## 2026-10 修订：聚焦区（桌面已实现，定稿 P4）

旅行者平时要同时盯着几件事，荧光绿底配黑字看久了眼花，子任务字也偏小。NOW 卡因此改成能放几件事的**聚焦区**，下文所有「NOW 卡」在桌面上都以这一节为准。设计稿（Claude Design 画布，私有）：https://claude.ai/artifact/VatZ8orrgdA7t7mqcfWqdu ——「定稿 P4」几块是最终结果，「底色对比」「纸白 + 荧光绿」「三种配色方向」是选型过程。

- **结构**：一整块圆角 20 的面板，顶上 `✦ NOW` 荧光绿标签 +「同时盯着 N 件」，右边「拖动排序」（拖进来时变成粗体「松手 = 加入聚焦」并整块描边）。每件一行，行间 1px 分隔：22 完成圈 + 标题（Display 之外的正文 600，15.5 / 宽窗口 17）+ 眼睛「送去验证」；悬停出现拖拽点，标题行右侧浮出 `↑`（移到最前）、`+`（添加子任务，点了才在子任务最后开空行）、`⋯`——悬停按钮一律浮在行内、盖住文字末尾，不占位置，悬停前后布局完全不动。有 2 个以上子任务时显示分段进度（完成段荧光绿）和 `1/3`。子任务 16 圆圈、13.5 字（宽窗口 14），整棵子树缩进 24。
- **颜色**（`src/styles.css` 的 `--z-*`）：浅色纸白 `#FFFFFF` 面板 + 1px `rgba(11,11,12,.07)` + 轻阴影，正文 `#0B0B0C`，完成圈黑、完成后黑底荧光绿勾，标题下荧光笔是压在字下半截的荧光绿（`rgba(214,255,61,.95)`，占行高 56%–94%）；深色炭灰 `#1C1C1F` 面板，正文 `#F4F4EF`，完成圈和进度荧光绿，荧光笔换成字下 2.5px 的荧光绿线。荧光绿上永远是近黑的字。
- **行为**：聚焦标记是 FOCUS 顶层项的数据（和列表、父项同一个同步寄存器），聚焦区总排在「接下来」前面；设为现在 = 放进聚焦区最前；新建、送进 FOCUS 排在聚焦区后面（FOCUS 原本空着时直接进聚焦区）；`⌘/Ctrl+↵` 新建并放进聚焦区；最后一件做完后不自动补，显示虚线框和「放进下一件」。
- **动效**：聚焦项完成 820ms（圈按下 .82 → 填黑画勾、外圈爆开 + 6 颗星芒、标题划线 → 淡出收起 → 星芒飞向 HISTORY）；子任务完成和普通行同一套 760ms；从「接下来」移进聚焦区时从原位置弹簧移上去并荧光绿闪一下。
- iOS 这一轮只跟上数据（见 `docs/ios.md` 开头），聚焦区界面另做。

## About the Design Files
`design/` 里是 HTML 做的设计参考（同一个窗口 / 屏幕组件用不同参数画出所有状态），**不是生产代码**。实现时用现有代码库重写：

- 桌面：`src/components/*`、`src/styles.css`、`electron/`（Mac 与 Windows 共用）。
- iOS：`src/mobile/*`、`src/mobile/mobile.css`、原生外壳 `ios/App`（iOS 26 原生页签栏、Duo 竖排由 Duo 会话接好）。
- 小组件：`ios/App/FocusWidget/*`（SwiftUI，小组件会话已建好扩展和数据快照）。

本地查看：

```bash
cd design_handoff_focus/design && python3 -m http.server 8790
```

然后打开 `http://localhost:8790/Mac.dc.html`（或 `Win`、`iPhone`、`Duo`、`Widgets`、`Brand`、`Spec`、`Motion`）。`FDesk.dc.html` / `FPhone.dc.html` / `FWidget.dc.html` 是组件本体，顶部 `data-props` 列出全部参数（os、theme、view、overlay、sync、form、posture…）。`screens/*.jpg` 是各画板的整张截图。

## Fidelity
**High-fidelity**：颜色、字号、间距、圆角、动效时序都是最终意图。示例文字是演示数据。三处需要实现方自己定的细节：原生页签栏的确切尺寸以系统为准（我们只指定颜色、图标、选中态）；小组件尺寸以系统给的为准；Windows 的 Mica 是否开启看性能。

## Platforms & Layout Modes
按可用宽度切，不按设备型号判断。

| 模式 | 触发 | 导航 | FOCUS 页布局 |
|---|---|---|---|
| 桌面 compact | 窗口宽 < 520（默认 384×680，最小 320） | 标题栏下一排**页签胶囊**：空间头像 + FOCUS / VERIFY / INBOX / GOAL / HISTORY；选中项展开显示名字 | NOW 卡 → 新建框 → 「接下来」→ 底部「今天 N 件 · 连续 N 天」 |
| 桌面 regular | 宽 ≥ 520 | 左侧栏 200：空间卡片（切换）、四个列表（图标 + 英文名 + 中文副标 + 数字）、HISTORY、底部回收站 | 同上，NOW 卡标题放大到 24 |
| iPhone 竖屏（compact） | 常规 iPhone、Duo 内屏竖握 | 顶部：空间头像（点开是空间 + 设置菜单）+ 标题（日期 / 列表名 · 数字），右侧一颗玻璃云朵；**底部 iOS 26 原生液态玻璃页签栏独占一行，上方是新建输入条（bottom accessory）** | 单列：NOW 卡 → 接下来 |
| 宽内容（spread） | 内容区宽于高且 ≥ 700pt：Duo 内屏横向、手机横屏 | 原生页签栏（Duo 上在右侧竖条） | **两页**：左页 NOW 卡 + 统计，右页新建框 + 接下来；以折痕为界 |
| Duo 外屏（合上） | 466×678，系统给 compact | 右侧 80pt 竖条：上面状态栏、头像 / 云朵（竖排玻璃胶囊），下面竖排玻璃页签，最下面荧光绿 + 钮 | 左侧 386×678 一整块单列，标题在内容顶部 |
| Duo 内屏（展开 / 半折） | 951×669 | 竖条在同一位置（84pt） | 左页 0–455 / 折痕 455–495 / 右页 495–867；展开和半折用同一版式 |

Duo 细节（Xcode 27.1 模拟器实测 + Apple「Designing for iPhone Duo」）：外屏 D 形（左侧铰链边近直角，右侧大圆角，前摄在右上角，处于竖条里）；外屏顶 / 底栏都挪到右侧竖条；内屏折痕 40pt 只在半折时生效，完全展开时宽 0，但我们**始终留出这 40pt**，所以开合不重排；折痕区不放可点元素；面板、菜单在双页时居中在右页。内屏竖握（669×951）竖向空间够，页签回到底部横排并居中。

开合连续：竖条位置不变；NOW 卡从外屏单列顶部以左上角为原点放大到左页（386→425 宽），队列行从卡下方滑到右页，每行错开 24ms，约 0.38s iOS 减速曲线；合上反过来。滚动锚点、编辑中的文字、选中列表沿用现有 iOS 版做法保留。

## Interactions & Behavior

### 需要改数据逻辑的地方（行为变化）
1. **NOW = FOCUS 里手动顺序排第一的未完成顶层项**，不加新字段。
2. **新建默认插到第 2 位**（NOW 之后），不抢 NOW。iOS 新建卡上「排在现在之后」开关可关；桌面 ⌘/Ctrl+Enter = 新建并设为现在。现在的规则是「新建的在前」，需要在 `model.ts` 的插入位置加一个「after first」选项。其它列表保持新建在前。
3. **送进 FOCUS（INBOX 星芒钮）也插到第 2 位**；想直接做就用「设为现在」。
4. **设为现在**：把这一件移到 FOCUS 顶层第 1 位（从别的列表来的会先移进 FOCUS）。拖到 NOW 卡上、右键菜单、左滑、长按菜单都能触发。
5. **队列行可以直接完成**（桌面悬停出现勾选圈、iOS 右滑），不必先变成 NOW。
6. 其余规则不变：FOCUS / VERIFY 顶层完成后进 INBOX 的已完成；子项完成留在父项下；送去验证的顶层项整棵进 VERIFY 并恢复未完成，子项原地挂「待验证」。

### 动效（详见 `screens/Motion.jpg` 和 `tokens.json → motion`）
- **完成 NOW · 换场（1000ms）**：0–80 按下（钮缩到 .82）→ 80–440 圆钮外圈爆开 + 6 颗星芒（12px，飞出 40–60px 并转 90°）→ 120–380 标题划线（2.5px 黑）→ 380–560 卡片向上抽走（-30px、转 -3°、缩到 .95、淡出，ease-in）→ 460–820 队列第 02 行变形成新的 NOW 卡（位置、高度、底色、字号同时过渡，弹簧曲线轻微回弹）→ 其余行上移重排序号，每行错开 30ms。触感 .rigid@0、.success@380；声音用现有完成提示音。
- **完成普通行（760ms）**：按下圈缩 .85 → 填列表色 + 画勾（120–360）→ 6 颗星芒迸出（浅色底用 #B8E600）→ 划线（200–420）→ 一颗星芒沿弧线飞向 HISTORY 页签 / 侧栏图标（460–760），图标放大 1.18 并冒「+1」。替代现有的粒子 + 光环 + 扫光，飞行目标从 INBOX 改为 HISTORY（逻辑上仍进 INBOX 已完成）。
- **送去验证（520ms）**：眼睛眨一下（scaleY 1→.1→1，160ms）→ 行染成 VERIFY 色 → 缩到 .3 沿弧线飞向 VERIFY 页签，高度收起，后面的行补位 → VERIFY 角标数字上翻。触感 .light。
- **设为现在（450ms）**：行浮起（1.03 + 阴影）→ 与 NOW 卡 FLIP 交换位置 → 荧光绿底交接。
- **新建（300ms）**：行高 0→46 撑开 180ms 并从上方 8px 落下，背景荧光绿 75% → 透明 600ms；输入框清空保持焦点。
- **切换列表（220ms）**：旧内容淡出下沉 0–120，新内容淡入并上升 8px 60–220；页签选中底由系统滑动（原生）；桌面 ⌘/Ctrl+1–5 同。
- **减少动态效果**：全部换成 150ms 交叉淡入，不飞、不迸、不回弹。
- 曲线：标准 `cubic-bezier(.2,.8,.2,1)`、退出 `(.4,0,1,1)`、弹簧 `(.3,1.25,.4,1)`；SwiftUI 可用 `.snappy` / `.bouncy(extraBounce: 0.15)`。

### 液态玻璃页签栏与新建输入条（iOS 26）
2026-10-18 改版（旅行者从三个方案里选了 A「底部输入条」）：原来页签栏旁边那颗独立的荧光绿 + 钮去掉，新建改成页签栏上方的一条原生玻璃输入条；⋯ 菜单并进头像。画板见 `screens/iOS-nav.jpg`（方案 A 全部画面）、`screens/iPhone.jpg`、`screens/Duo.jpg`、`screens/Spec.jpg`；没选的 B、C 方案在画布「iOS 顶栏与新建」页。

**页签栏**
- **用原生**：`UITabBarController` / SwiftUI `TabView`，系统负责液态玻璃材质、滚动时收缩、Duo 外屏和内屏横握时竖排；网页内容层不画底栏。
- 五个页签，**独占一整行**（左右内缩 16、底距 24，系统决定高度，约 64）：FOCUS（星芒）、VERIFY（眼睛勾）、INBOX、GOAL、HISTORY。标签英文大写，图标 23；图标用交接包的描边 SVG（模板图上色）。
- **选中态**：系统的选中胶囊颜色改不了，只给选中项的图标和文字上色：浅色近黑 `#0B0B0C`，深色荧光绿 `#D6FF3D`；未选中是正文色。（设计稿里画的荧光绿胶囊只是网页降级时的样子。）
- **角标**：FOCUS / VERIFY / INBOX 显示未完成顶层项数（数字），GOAL / HISTORY 不显示。
- 不再有独立的 + 钮，也不要把新建做成第 6 个页签。

**新建输入条（bottom accessory）**
- **实现**：`tabBarController.bottomAccessory = UITabAccessory(contentView:)`（SwiftUI `.tabViewBottomAccessory { }`）。系统把它画成页签栏上方的一条液态玻璃胶囊（设计稿：50 高、圆角 25、左右与页签栏对齐、与页签栏间距 10）。
- **内容**：左边 34 圆、荧光绿 `#D6FF3D` 底、近黑「+」；中间是这一页的提示语（15 字号，次要文字色）；右边小字是新建会落到哪个列表（列表图标 + 英文名，Bricolage 800 10.5，字距 .06em）。

| 页面 | 提示语 | 右边 |
|---|---|---|
| FOCUS | 接下来要做… | ✦ FOCUS（默认排在 NOW 之后） |
| VERIFY | 做完了、还要测一下的事… | VERIFY |
| INBOX | 想到什么，先丢进来… | INBOX |
| GOAL | 写下一个长期目标… | GOAL |
| HISTORY | 不显示（`bottomAccessory = nil`，带动画） | — |

- **点它**：输入条原地长成现在那张贴着键盘的新建卡（列表芯片、「排在现在之后」开关、荧光绿发送钮都不变），键盘弹出时页签栏和输入条一起收起；关掉新建卡又缩回输入条。
- **滚动时**：`tabBarMinimizeBehavior = .onScrollDown` 时系统把页签栏收成一颗、输入条并到它旁边（inline 摆法，读 `tabAccessoryEnvironment` 切成只剩「+ 提示语」的窄版）。内容是网页在滚，系统不一定能感知到滚动；收不起来就保持常驻，可以接受。
- **手机横屏**：页签栏和输入条在底部同一行（inline），见 `iOS-nav.jpg` A7。
- **Duo 竖排**（外屏、内屏横握）：系统竖排时配件栏的摆法需要实机确认；如果放不进竖条，就不设 accessory，退回现在的做法：竖条最下面一颗 58 的荧光绿 prominent「+」。内屏右页顶上的「接下来要做…」照留。Duo 内屏竖握与 iPhone 相同（输入条 + 页签栏横排居中）。
- 撤销提示条等底部浮层要放在输入条上方（设计稿 bottom 160）。

**玻璃参数**（网页里画头像菜单、新建卡、降级时的栏用）：浅 `rgba(255,255,255,.56)` / 深 `rgba(38,38,42,.52)`，`backdrop-filter: blur(22px) saturate(180%)`，内描边 1px 白 85% / 13%，顶部 1px 高光白 95% / 22%，阴影 `0 8 24 rgba(0,0,0,.12)` / `0 10 28 rgba(0,0,0,.4)`。滚动边缘：内容滚到玻璃下面，底部约 170pt 渐隐到页面底色（`scrollEdgeEffect`）。辅助功能：减少透明度时玻璃换成不透明 surface；增强对比时描边加深到 30%。
