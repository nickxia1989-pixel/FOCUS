# FOCUS

一个窄而高的桌面 TODO 小窗，Windows / macOS 通用。

左侧栏有四个列表和一个完成记录：

| 分区 | 用途 |
| --- | --- |
| **FOCUS** | 当下要完成的具体事情 |
| **VERIFY** | 待测：做完了但还要测一下，测完才算结束 |
| **INBOX** | 想到什么先丢进来 |
| **GOAL** | 长期大目标 |
| **HISTORY** | 完成记录：按日期查看哪天完成了哪些事 |

典型流程：INBOX →（◎）→ FOCUS → 做完直接勾掉，或点烧瓶标为待测 → VERIFY → 测完勾掉 → INBOX 的已完成。

## 功能

- **Profile**：可以建多个互相独立的数据空间（例如"工作""生活"），各自的待办、回收站、当前分区互不干扰
  - 点左侧栏顶部的头像（或 `Ctrl/⌘ + Shift + P`）打开 profile 菜单，点名字或按数字键切换
  - 菜单里可新建；悬停某个 profile 可改名、删除（删除要再点一次确认；数据移到 `deleted-profiles/` 存档，不会真的删掉）
  - 有多个 profile 时，内容区标题会带上当前 profile 名
- **左侧栏**：窗口窄时只显示图标和角标，拉宽到 520px 以上自动显示文字
  - 列表图标上显示该列表**未完成**的数量（含子项），HISTORY 上显示今天完成了几件
- **完成记录（HISTORY）**：
  - 顶部是今天 / 本周完成数和连续完成天数
  - 热力图显示最近几个月每天完成了多少，列数随窗口宽度变化；点某一天跳到那天的记录
  - 下面按天分组列出完成的事和完成时间，圆点颜色表示在哪个列表完成；同一天一起完成的子项挂在父项下，单独完成的子项会标出父项
  - 悬停可「恢复为未完成」
  - 点底部的「今天完成了 N 件事」也能进入
- 每个列表顶部输入框直接新建，回车后保持焦点可连续输入
- 勾选完成 / 再点一次取消完成
- 排序：未完成在前；同状态下新建的在前；同层、同状态内可**拖拽**调整顺序
- 列表间移动：
  - INBOX 顶层未完成项右侧常驻 **◎ 按钮**，一键送进 FOCUS
  - 把条目**拖到左侧栏的列表图标**上即可移到那个列表
  - 右键 / `⋯` 菜单里的「移到 …」
- 标为待测：
  - FOCUS 顶层未完成项右侧常驻 **烧瓶按钮**；其它条目悬停时也有烧瓶按钮，右键菜单里有「标为待测」
  - **顶层项**标为待测：整棵（含子项）进入 VERIFY，该项本身恢复为未完成，等测完再勾
  - **子项**标为待测：留在父项下、不换页签，勾选框变成青绿虚线圈并挂上「待测」标签；点标签或再点烧瓶可取消
  - VERIFY 顶层项悬停有 ◎ 按钮：没测过就一键退回 FOCUS
- 完成：FOCUS / VERIFY 的顶层项完成后自动移到 INBOX 的已完成；**子项完成永远留在父项下**，不换页签
- 子 TODO：悬停点 `+` 或右键「添加子任务」，可无限嵌套，用缩进 + 连线显示层级；父项右侧胶囊显示进度并可折叠
  - 移动父项时子孙一起移动；单独移动子项会让它脱离原父项，成为目标列表的顶层项
  - 完成父项时子孙一并完成
- 完成动画：勾选弹跳、粒子与光环、整行扫光、删除线划过、提示音（可在 `⋯` 菜单关闭，所有 profile 共用），FOCUS / VERIFY 完成项会飞向侧栏的 INBOX；标为待测时也有一小簇粒子并飞向 VERIFY
- 双击文字编辑；删除后 5 秒内可直接在提示条上撤销
- 回收站：平时隐藏，从标题栏 `⋯` 菜单进入
  - 删除的条目连同子项整组保留 30 天，过期自动清除
  - 显示原列表、原父项、子项预览和删除时间
  - 「恢复」回到原来的位置：原父项还在就挂回父项下，否则作为顶层项回到原列表
  - 单条「彻底删除」和「清空」都需要再点一次确认
- 窗口可置顶（标题栏图钉），位置、大小、置顶状态自动记住
- 跟随系统浅色 / 深色模式

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + 1 / 2 / 3 / 4 / 5` | 切换 FOCUS / VERIFY / INBOX / GOAL / HISTORY |
| `Ctrl/⌘ + Shift + P` | 打开 profile 菜单；菜单里按数字键切换 |
| `Ctrl/⌘ + N` | 聚焦新建输入框（在 HISTORY 时先回到 INBOX） |
| `Enter` / `Esc` | 确认 / 取消（新建、编辑、子任务输入） |
| `Ctrl/⌘ + Z` | 撤销刚才的删除 |
| `Esc`（拖拽中） | 取消拖拽 |
| `Esc`（回收站中） | 关闭回收站 |
| `⌘ + W`（macOS） | 关闭窗口（应用留在 Dock，点图标重新打开） |

## 数据存放

数据是本地 JSON 文件（每次改动约 0.25 秒后原子写入，关窗前同步落盘），放在：

- Windows：`%APPDATA%\FOCUS\`
- macOS：`~/Library/Application Support/FOCUS/`

| 文件 | 内容 |
| --- | --- |
| `profiles.json` | profile 列表、当前 profile、全局设置（提示音） |
| `focus-data.json` | 「默认」profile 的数据（升级前的数据就在这里，位置不变） |
| `profiles/<id>.json` | 其它 profile 的数据，每个一个文件 |
| `deleted-profiles/` | 删除的 profile 的数据存档 |

每次读入时会把能正常读取的文件备份为同名的 `*.bak.json`；主文件损坏时自动用备份恢复。第一次打开带 profile 的版本时，原有数据自动成为「默认」profile。
`⋯` 菜单里的「打开数据文件夹」可直接打开该目录。设置环境变量 `FOCUS_USER_DATA` 可改用其它目录。

## 开发

需要 Node.js 22.12+。

```bash
npm install
npm run dev        # Vite 开发服务器 + Electron 窗口，改代码热更新
npm run dev:web    # 只在浏览器里跑界面（数据存 localStorage），方便调样式
npm test           # 数据逻辑单元测试
npm run build      # 类型检查 + 打包前端
npm start          # 构建后用 Electron 运行
```

## 打包

```bash
npm run dist:win   # 在 Windows 上：生成安装包和免安装版 exe
npm run dist:mac   # 在 macOS 上：生成 dmg 和 zip
```

产物在 `release/` 目录。macOS 包需要在 Mac 上构建；未签名的 Mac 应用首次打开需要右键「打开」。
应用图标由 `npm run icon` 从 `scripts/make-icon.cjs` 里的 SVG 生成到 `build/icon.png`。

## 结构

```
electron/main.cjs      主进程：窗口、文件读写、IPC
electron/preload.cjs   向页面暴露 window.focusApi
src/model.ts           纯数据操作（排序、移动、完成、子树…），有单元测试
src/trash.ts           回收站：删除入站、恢复到原处、过期清理，有单元测试
src/history.ts         完成记录：按天分组、热力图、连续天数，有单元测试
src/store.ts           zustand 状态、profile 切换与持久化
src/actions.ts         带动画反馈的高层操作
src/dnd.ts             拖拽排序 / 拖到页签
src/effects.ts         粒子、飞行小球、提示音
src/components/        界面组件（Sidebar 侧栏、ProfileMenu、HistoryView…）
```
